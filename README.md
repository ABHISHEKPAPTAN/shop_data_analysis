# 🛍️ Shop Data Analysis Project (Vrinda Store Analytics)

Ek comprehensive retail sales aur customer data analysis project jise Microsoft Excel ka use karke banaya gaya hai. Is project ka mukhy uddeshya online sales trends, customer behavior, aur channel-wise performance ko track aur analyze karna hai.

---

## 📊 Project Overview

- **Dataset File:** `shop data analysis projesct.xlsx`
- **Total Transactions/Orders Analyzed:** 31,047+ records
- **Total Sales Amount:** ~₹2.11 Crore+ (INR)
- **Primary Tools Used:** Microsoft Excel (Pivot Tables, Charts, Data Cleaning, Formulas)

---

## 🔍 Key Insights & Analysis (Aapne Isme Kya Analyze Kiya Hai)

Is project me shop/store ke sales data ko alag-alag angles se analyze kiya gaya hai:

1. **Sales & Orders Trends:** 
   - Monthly sales performance track ki gayi hai taaki pata chal sake kis mahine me sabse zyada revenue generate hua.
2. **Channel-wise Performance:** 
   - Alag-alag e-commerce channels (jaise Amazon, Myntra, Flipkart, Ajio, Nalli, Meesho, etc.) par total orders aur sales ka comparison kiya gaya hai. Sabse zyada orders Amazon aur Myntra se aaye hain.
3. **Category Breakdown:** 
   - Products ki categories (jaise Set, Kurta, Western Dress, Top, Saree, Ethnic Dress, Blouse, Bottom) ki demand aur sales analysis ki gayi hai.
4. **Demographics (Gender & Age Analysis):** 
   - Customers ke gender aur age groups (Teenagers, Adults, Seniors) ko analyze kiya gaya hai jisme yeh samne aaya ki women customers ki kharidari sabse zyada hai (~21,500+ orders).
5. **Order Status Tracking:** 
   - Delivered, Returned, Cancelled, aur Refunded orders ka status breakdown nikal kar store ki fulfillment efficiency ko measure kiya gaya hai (jisme majority orders successfully Delivered hue hain).
6. **Top Cities & States Sales:** 
   - Top performing cities aur states ki list tayar ki gayi hai jahan sabse zyada shipping aur sales hui hai.
